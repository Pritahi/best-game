## Controls

- **WASD / Arrow Keys**: Move your tiny survey skiff.
- **SPACE (Hold)**: Unfurl a luminous survey trail while sailing.
- **SPACE (Release)**: Close the trail near its start (within 48px) to seal rifts inside the polygon.
- **SHIFT**: Tactical dodge (provides brief invulnerability).
- **P**: Pause / Unpause.
- **M**: Mute / Unmute.
- **R**: Restart game.

## Goal

Survey the ink-stained maps and seal the glowing beacons trapped within rifts. Survive 3 tides and manage your hull integrity and thread levels to succeed.

## Technical

Built with vanilla JavaScript and Canvas API. No external dependencies.
